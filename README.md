## How it works

`main.ts` holds the roast as a single string, checks it against the
bounty gates (one non-blank line, 1–200 characters, no newline inside),
then writes it to `/output/entry.txt` where the sealed scorer reads it.

## Run it

```bash
node main.ts
```

Requires Node 22.18+ (which runs TypeScript directly, no build step).
